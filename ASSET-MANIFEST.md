# Asset Manifest — Nishal Interiors by Nishita

Every photograph must be an original high-resolution file from the client, not an
Instagram download, with written permission from the homeowner for any published
home photo. Until files arrive, the site renders a neutral sand-coloured placeholder
block at the correct aspect ratio with a label describing the image needed.

A `{{NEED: ...}}` token in the source marks a missing fact. The production build guard
must fail if any token remains.

## Facts needed from Nishita

1. Studio address (for footer, contact page, schema NAP)
2. Phone number (tel: and WhatsApp click-to-chat)
3. Contact email address (replaces placeholder hello@nishalinteriors.com if different)
4. Number of years the studio has been practising (for About page)
5. Three short answers in Nishita's own words for the About page:
   - "A room I keep going back to"
   - "A material I trust"
   - "Something site work taught me"
6. Areas of Mumbai actually served (only real areas get /areas/[area-name]/ pages)
7. Pricing model and how quotes are built (for /pricing-and-how-we-charge/)
8. Real project list: brief, layout problem, materials, what changed, location
   (area only unless client agrees), year, photographer credit
9. FAQ questions clients actually ask, with real answers
10. Journal article topics the client approves for publishing (8 to 12 guides)
11. Google Form enquiry URL (current enquiry method)
12. Final production domain (replaces placeholder https://nishalinteriors.com)
13. Instagram confirmation (@nishal_interiors)
